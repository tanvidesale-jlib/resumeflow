# ResumeFlow\n\nResumeFlow is a private resume workspace for shaping experience into a clear, memorable story.\n\n## Live site\n\nThe frontend is published on GitHub Pages at:\nhttps://tanvidesale-jlib.github.io/resumeflow/\n\nThe repository contains the full pnpm workspace: Vite/React frontend, Express API, PostgreSQL/Drizzle persistence, generated API clients, and Clerk integration.\n\n## Deployment\n\nGitHub Pages serves the static frontend. The Express API and PostgreSQL database run separately because GitHub Pages cannot execute server code. A Render Blueprint is included at render.yaml.\n\n### Render backend\n\n1. In Render, create a new Blueprint from this repository and select render.yaml.\n2. The Blueprint creates a free resumeflow-api web service and a free resumeflow-db Postgres database.\n3. Enter CLERK_PUBLISHABLE_KEY and CLERK_SECRET_KEY as Render environment variables. Do not commit either key.\n4. Initialize the database schema once after the database is created:\n\n   DATABASE_URL="<Render external database URL>" pnpm --filter @workspace/db run push\n\n   Run that command from a local checkout or an environment with the repository dependencies installed.\n5. Copy the deployed API URL. The health check is /api/healthz.\n\nRender’s free web service sleeps after inactivity, and its free Postgres database is intended for testing/hobby use and expires after 30 days.\n\n### GitHub Pages frontend\n\nThe Pages workflow in .github/workflows/deploy-pages.yml rebuilds the frontend using these repository variables:\n\n- VITE_API_URL — the Render API URL, without a trailing slash\n- VITE_CLERK_PUBLISHABLE_KEY — the public Clerk key\n- VITE_CLERK_PROXY_URL — optional; defaults to VITE_API_URL/api/__clerk\n\nAfter adding the variables, run the workflow once from the Actions tab. Future pushes to main rebuild and publish the frontend automatically.\n\n## Environment variables\n\nSee .env.example for local, GitHub Pages, and Render variable names.\n\nNever commit DATABASE_URL or CLERK_SECRET_KEY.\n\n## Local development\n\n~~~bash\npnpm install\npnpm run typecheck\nPORT=4173 BASE_PATH=/resumeflow/ pnpm --filter @workspace/pathfolio run build\nPORT=5000 DATABASE_URL="<your Postgres URL>" pnpm --filter @workspace/api-server run dev\n~~~\n\n## Stack\n\n- pnpm workspaces, Node.js 24, TypeScript 5.9\n- Vite/React frontend\n- Express 5 API\n- PostgreSQL + Drizzle ORM\n- Clerk authentication\n
